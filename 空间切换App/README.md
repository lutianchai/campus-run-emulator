# 空间切换

自有 Android 测试工具。每个空间对应一个 Android 用户，应用登录数据互相隔离。支持创建、切换、删除空间及启动适配应用。长按标题会将诊断结果写入应用私有目录 `files/diag.txt`。

通过 `127.0.0.1:5555` 的本机 adbd 执行命令，要求隔离模拟器中 `ro.adb.secure=0` 且 adbd 有 root 权限；不是普通真机通用切换器。删除空间会连带删除其中的数据，界面会先确认。

构建：设置 JDK 21 的 `JAVA_HOME`，运行 `./构建.sh`。默认 SDK 为 `../运行环境/sdk`，支持 `ANDROID_HOME` 覆盖；默认 build-tools 为 `35.0.0`，支持 `ANDROID_BUILD_TOOLS` 指向工具目录。

构建不依赖 Gradle：aapt2 → javac → d8 → zipalign → apksigner。密钥不存在时自动在本目录生成 `keystore.jks`，仅用于测试签名，密钥永不入库。公开 APK 使用此次构建新生成的匿名测试证书，不含旧签名私钥。重新生成密钥后与旧签名不兼容，更新可能需要先卸载（会删除工具本身数据）。

安装：回到仓库根目录运行 `./安装空间切换.command`。

连接必须在长命令完成前保持打开，否则 adbd 可能终止会话中的切换与启动命令。日志含设备用户名称，不要直接附到公开问题中。
