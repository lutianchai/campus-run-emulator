# 常见问题

- **地图闪退**：保留 `-gpu swangle` 软件渲染。原环境遇到地图 SDK EGL 上下文创建失败；这是环境记录，不保证所有版本都相同。
- **星数为 0**：确认目标应用正在请求定位，检查 GNSS 文件哈希和服务；刚开机应稍等重试。补丁是合成卫星状态。
- **轨迹不动**：确认模拟器控制台端口 5554、令牌文件存在且认证成功、应用确实在申请定位；不要把令牌内容贴到 issue。
- **有网标识但连不上**：运行修复网络入口；它可能关闭并重启整个模拟器。检查宿主机代理/VPN、业务服务与探测目标的连通性差异。
- **切换空间失败**：检查 `ro.adb.secure`、root adbd 和 5555 本机连接条件。不要为了使用本工具关闭真实设备的安全保护。
- **APK 更新签名不一致**：公开版使用新测试证书。旧本机密钥未公开；自行重建也会产生新证书。卸载前确认应用数据影响。
- **找不到 SDK**：先运行安装环境入口，确认 SDK 位于仓库的 `运行环境/sdk/`；运行入口固定用此目录，APK 构建才额外支持 ANDROID_HOME。
- **启动总结果成功但仍有提示**：定位/网络等部分项为警告，不一定进入失败计数；检查每一项状态，应用页面仍需人工验证。
